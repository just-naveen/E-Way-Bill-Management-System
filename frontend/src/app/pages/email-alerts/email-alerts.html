How It Works
1
Every day at {{ config.send_time }}, the system scans all active E-Way Bills
2
Bills expiring within {{ config.alert_hours_before }} hours are collected
3
One email is sent to all {{ config.recipient_emails.length || 0 }} recipient(s) with the full list
4
Django runs this automatically via manage.py send_ewb_alerts + a cron job
Recommended cron (runs daily at set time):
0 8 * * * cd /path/to/project && python manage.py send_ewb_alerts
